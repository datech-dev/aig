# Agent Instructions & Project Guidelines

## Primary Platform Focus
- **Android Application Only**: All future application features, UI/UX updates, bug fixes, and enhancements must target the **Android application (`juhi_app/`)** and the supporting REST API / backend services (`webhook_server.py`, `database.py`, `ai_engine.py`, etc.).
- **No Telegram Bot Updates**: Do NOT make updates to or prioritize the Telegram bot (`bot.py`) unless the user explicitly requests Telegram bot changes.
